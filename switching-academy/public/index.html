💾 Progress codes and backup files

What is this for?

Your progress (ticked topics, finished tickets, stars) is saved to your Switching Academy account while you're signed in, so it shows up on any computer, tablet or phone where you sign in. A progress code or backup file is an extra copy you can keep, or send to a teacher or parent.

Your progress code is a short piece of text that holds all of your progress. Copy it somewhere safe, and paste it back in whenever you need to.

How to save your code

  1. Tap Get my progress code.
  2. Tap Copy code, or select the text in the box and copy it.
  3. Keep it somewhere you can find again, such as a note on your phone, a message or email to yourself, or a school document.
  4. Prefer a file? Tap Download backup file instead. It saves the same code as a small text file.

How to load your code

  1. Open Switching Academy on the new device (or after clearing your browser).
  2. Open this box, paste your code into the text box below.
  3. Tap Load my progress. The page will refresh with your progress back.
  4. Saved a backup file? Tap Load a backup file and pick it instead.

How to show a teacher or parent

  1. Tap Get my progress code, then Copy code.
  2. Send the code to your teacher or parent, for example by email or your class website.
  3. They open Switching Academy on their own device and paste it into the Teachers & Parents tab.

Your code shows your progress at the moment you make it. Send a new code whenever you want to show newer progress.

Loading a code adds to what is already on this device. It never removes progress you have already made here. Only paste codes that you saved from this site yourself.

⚠️ This browser isn’t keeping your progress right now. This can happen in a private window, or when site storage is blocked. Save a code or a backup file before you close the page.

📱 Devices on a network

Desktops, laptops, phones, printers and more
🖥️ Desktop PC
What it is: a computer that stays in one place, usually plugged into a switch with a cable. What it is for: everyday work like homework, browsing and games. It is an end device: it uses the network but does not run it.
💻 Laptop
What it is: a portable computer. What it is for: the same jobs as a desktop, but you can carry it around. It can plug in with a cable or join the network wirelessly through an access point.
🖨️ Printer
What it is: a device that puts documents on paper. What it is for: sharing printing, so everyone on the network can use one printer instead of each person needing their own.
🗄️ Server
What it is: a powerful computer that gives services to other devices. What it is for: storing shared files, hosting websites, or handing out IP addresses (DHCP). Think of it like a school library that lots of people borrow from.
📡 Modem
What it is: the box from your internet provider (ISP) that brings the internet into your home. What it is for: it is the doorway from the outside. Your own router plugs into it. Some ISP boxes are a modem and a router in one.
📶 Access Point
What it is: a box that sends and receives Wi-Fi signals. What it is for: letting wireless devices like phones and laptops join the wired network. It plugs into a switch with a cable.
🧱 Firewall
What it is: a security device (or program) that checks traffic. What it is for: blocking anything that breaks the rules and keeping threats out. It usually sits between your network and the internet, like a security guard at the gate.
☁️ Internet
What it is: a huge worldwide collection of connected networks. What it is for: reaching websites, videos, email and games outside your own network. Your router is the doorway to it.

Switches and routers are explained in the next list. You can place every one of these devices in the Network Builder tab.

📖 Words to know

Glossary and printable cheat sheet
Network
Devices connected so they can share information.
Switch
A box that connects devices in the same network and sends messages to the right one.
Router
A device that connects different networks, like your home and the internet.
Port
A socket on a switch where a cable plugs in.
MAC address
A unique ID built into a device’s network card.
IP address
A network address that tells messages where to go.
VLAN
A virtual network that splits one switch into separate groups.
Trunk
A link between switches that carries several VLANs.
DHCP
A service that gives devices their addresses automatically.
ACL
An access list: rules that allow or block traffic.
Loop
When messages travel in a circle forever and clog the network.
CLI
The command line, where you type commands to set up a switch.
Spanning Tree
Rules that switches follow to find and block loops, while keeping a spare path ready.
Port security
Settings that limit which devices, and how many, can use a switch port.
Gateway
The router a device sends messages to when they need to leave its own network.
DNS
A service that turns names like example.com into IP addresses, like a phone book.
Implicit deny
The hidden last rule of an access list: anything not allowed is blocked.
Packet Tracer
A free Cisco program for building and testing pretend networks on a computer.

🛡️ Ground rules

Stay safe and legal
  • Practice on simulators and your own lab equipment only.
  • Never plug into, scan, or change a network at home, school, or anywhere else without permission from the person who runs it.
  • Use strong passwords and never share them, even in practice labs.

    Good to know
    

      

    • A code is a snapshot of progress at the moment it was made, not a live view. Ask learners to send a fresh code whenever you want an update.
      • 

    • Codes aren’t locked or signed, so a tech-savvy learner could edit or swap one. They’re fine for checking in on progress, but don’t rely on them for grades.
      • 

    • Topic ticks (“I understand this one”) are the learner’s own judgement, and the certificate unlocks when all 10 are ticked. For firmer evidence, look at review quiz stars and finished labs, which are checked by the site.
      • 

    • Progress is saved to each learner's account while they're signed in, so it follows them between devices. Progress codes and backup files still work if you want an extra copy.
      • 

    • Text size, easy-read text and a light or dark theme are under the header. The Network Builder works with a keyboard, and the site supports screen readers.
      • 

    • The practice switch uses Cisco-style commands. It’s a learning tool, not real switch software. The What a real switch looks like diagram in the Practice tab links it to real hardware.
      • 

    • Our Facebook page posts updates. Facebook requires users to be at least 13, so younger learners may want an adult to follow it for them.
